# Omatide

Tides and currents for [Omahoy](https://github.com/shieldsworks/omahoy), offline.

**Status: planned.** Nothing to install yet.

## What it will do

- Predict tide heights and currents on the boat itself, from NOAA harmonic
  constants.
- Choose stations near the boat, starting with San Francisco (9414290).
- Show the next high or low water and the next slack in a bar widget.
